# 現場指摘ノート

新築工事の品質指摘を、写真とコメントで記録・共有し、傾向分析やチェックリストに活かすWebアプリです。
スマホのブラウザで開いて使います。保存先は「この端末だけ」と「共有フォルダ（SharePoint / Teams）」を設定画面で切り替えられます。

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体 |
| `msal-browser.min.js` | Microsoft のサインイン用ライブラリ（@azure/msal-browser 3.27.0、MIT ライセンス） |

共有フォルダの中には、アプリが次のフォルダを自動で作ります。

| フォルダ | 内容 |
|---|---|
| `issues/` | 指摘 1 件ごとの JSON（一覧用の縮小画像を含む） |
| `photos/` | 指摘写真（JPEG） |
| `checklist/` | チェック項目 1 件ごとの JSON |
| `settings/trades.json` | 工種リスト |

チェックを付けた状態は各自の端末に保存され、他のメンバーとは共有しません。

## 初期設定（最初の 1 回だけ）

### 1. アプリを Microsoft 365 に登録する

1. https://entra.microsoft.com に会社のアカウントでサインインします。
2. 「アプリケーション」→「アプリの登録」→「新規登録」を開きます。
3. 次のとおり入力して「登録」を押します。
   - 名前：`現場指摘ノート`
   - サポートされているアカウントの種類：「この組織ディレクトリのみに含まれるアカウント（シングルテナント）」
   - リダイレクト URI：プラットフォームに「シングルページ アプリケーション (SPA)」を選び、アプリの URL（例：`https://<GitHubユーザー名>.github.io/genba-shiteki/`）を入力します。末尾の `/` まで正確に入れてください。
4. 「概要」に表示される次の 2 つを控えます。
   - アプリケーション（クライアント）ID
   - ディレクトリ（テナント）ID
5. 「API のアクセス許可」→「アクセス許可の追加」→「Microsoft Graph」→「委任されたアクセス許可」で `Files.ReadWrite.All` にチェックを入れて追加します。
   - この権限は、サインインした本人がアクセスできるファイルだけを読み書きするものです。
   - 管理者の同意が不要な権限なので、各メンバーが初回サインイン時に自分で同意します。
   - 同意の画面で「管理者の承認が必要」と表示された場合は、会社の設定で利用者による同意が制限されています。情報システム担当に、このアプリへの「管理者の同意」を依頼してください。

### 2. 共有フォルダを用意する

1. 指摘を集める Teams のチーム（または SharePoint サイト）の「ファイル」に、フォルダ（例：`現場指摘ノート`）を作ります。
2. フォルダの「…」→「リンクをコピー」でリンクを取得します。
3. アプリを使うメンバー全員が、このフォルダを**編集できる**必要があります。チームのメンバーであれば通常は編集できます。

### 3. アプリに設定する

1. アプリを開き、「出力・設定」→「保存先」で「共有フォルダ（SharePoint）」を選びます。
2. 1 で控えた 2 つの ID と、2 のフォルダのリンクを入力して「サインインして接続」を押します。
3. 会社のアカウントでサインインすると、共有フォルダとの同期が始まります。画面右上に「共有：同期済み」と表示されれば完了です。
4. それまで端末だけに保存していた記録がある場合は、「この端末の記録を共有フォルダへ送る」を押します（サンプルは送りません）。

### 4. メンバーに配る

1. 「メンバー用リンクを作る」を押し、表示されたリンクをコピーしてメンバーに送ります（メールや Teams のチャットなど）。
2. メンバーはスマホでリンクを開き、「サインイン」を押して会社のアカウントでサインインするだけで使えます。
3. ホーム画面に追加しておくと、アプリのように開けます（iPhone は共有ボタン →「ホーム画面に追加」、Android は Chrome のメニュー →「ホーム画面に追加」）。

## 使い方の注意

- 電波がないときは端末に保存し、画面右上に「共有：未送信 n」と表示します。つながると自動で送信します。
- 他のメンバーの記録は、アプリを開いたとき、画面に戻ったとき、2 分ごとに取り込みます。「今すぐ同期」でも取り込めます。
- 同じ指摘を 2 人が同時に編集した場合は、後から保存した内容が残ります。
- 指摘番号（No.）は端末ごとに採番するため、まれに同じ番号が重なることがあります。
- 保存先を「この端末だけ」に戻しても、共有フォルダから受け取った記録は端末に残ります。
